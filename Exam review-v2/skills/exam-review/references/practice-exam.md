# Mode: PRACTICE EXAM

Expensive in tokens and in his time. **Do not stop to ask a menu of questions
first** — default and state the assumption in one line, so he can override
before you're deep in.

Default: **20 questions, all-at-once** (full exam → he submits answers → you
grade). State it in one line, then generate. If he says "graded as I go,"
switch to one question at a time with immediate grading.

If he mentions being low on usage, offer the short version in one line —
10 questions, multiple choice and short answer only, no calculations — and let
him pick before you generate.

## Format matching is the whole value

Build the exam in the question forms **his actual course uses**. The class
Project contains examples of how this course structures its exams — read them
first and match the structure, weighting, and phrasing style. Fall back to the
syllabus or the professor's decks only if those examples are absent. If that isn't
available, say so, then use this default mix and label it a guess:

- ~40% multiple choice / matching (definitions, term boundaries)
- ~30% scenario-to-category (given a situation, name the concept)
- ~20% short answer (explain, contrast, justify)
- ~10% calculation or applied problem, for quantitative courses

## Rules

- **No answer key inline.** Answers, explanations, and scoring come only after
  he submits. An exam with the key attached is a reading exercise.
- **Weight coverage toward `gaps.md`, but not exclusively.** An exam testing
  only his known weak spots can't tell him whether the rest held — which is
  the question a practice exam is supposed to answer.
- **At least two questions combining concepts from different sections.** Real
  exams do this; single-concept practice doesn't prepare for it.
- **Plausible distractors** on multiple choice. Wrong options should be the
  actual common confusions, not filler — a question with three obviously wrong
  options tests nothing.
- **Report per-topic scores, not just a total.** A uniformly shaky 75% and a
  75% with one collapsed topic need opposite responses.
- End with the gap block for everything missed.
