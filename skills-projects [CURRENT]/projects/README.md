# Projects

Instructions for a claude.ai Project, a Gem, or a custom GPT: one folder per project, with the instructions ready to paste and a short note on any knowledge files it expects.

> **Tailored, not turnkey:** every project here (current and retired) was written for one person's own setup: their courses, accounts, hardware, tastes and knowledge files. Expect to edit names, rules and knowledge files before it works for you.

- [IS265](<IS265/README.md>): course Project for study help and a `!homework` drafting command.
- [new-games](<new-games/README.md>): game backlog picks, deal verdicts, and `library.json` upkeep.
- [prompt,project,skill-creator](<prompt,project,skill-creator/README.md>): tightens prompts and drafts Project instructions, `!` commands and patch fixes.
- [research-items](<research-items/README.md>): ranked, cross-checked shopping research, then availability and links.
